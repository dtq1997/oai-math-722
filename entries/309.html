素数三的 Kervaire 不变量问题

The Kervaire invariant problem at the prime three

OpenAI · 2026-10-061 篇论文未见公开 Lean 代码

解决了素数三处的奇素数 Kervaire 不变量问题：在模三 Adams 谱序列中，恰好是指标为 000、222 和 333 的标准类存活，分别位于 stem 101010、106106106 和 322322322。

每个存活的检测陪集中都含有一个加法阶恰为三的元素。

英文原文

Resolves the odd-primary Kervaire invariant problem at the prime three: exactly the standard classes with indices 000, 222, and 333 survive in the mod-three Adams spectral sequence, in stems 101010, 106106106, and 322322322.

Each surviving detection coset contains an element of exact additive order three.

论文

  1. 素数三处的 Kervaire 不变量问题

    The Kervaire invariant problem at the prime three

    摘要

    我们解决模三 Adams 谱序列中标准 Kervaire 类在素数三处的 Kervaire 不变量问题。

    这些类恰在指标 0、2 和 3 处存活，且每个存活的检测陪集中都含有一个加法阶为三的元素。

    特别地，在第 322 个稳定茎中存在一个三阶 Kervaire 元素。

    英文原文

    We solve the Kervaire invariant problem at the prime three for the standard Kervaire classes in the mod-three Adams spectral sequence.

    These classes survive precisely at indices 0, 2, and 3, and each surviving detection coset contains an element of additive order three.

    In particular, there is an order-three Kervaire element in stem 322.
