β-Barendregt–Geuvers–Klop 猜想

The β\betaβ-Barendregt–Geuvers–Klop conjecture

OpenAI · 2026-10-061 篇论文Lean 代码已公开

证明了对每个纯类型系统，弱正规化蕴含强正规化：如果每个有效上下文中的每个合法表达式都有一个β\betaβ-正规形，那么每个β\betaβ-归约序列都终止。

这解决了β\betaβ-Barendregt–Geuvers–Klop 猜想，包括非函数性规则和开放上下文的情形。

英文原文

Proves that weak normalization implies strong normalization for every pure type system: if every legal expression in every valid context has a β\betaβ-normal form, every β\betaβ-reduction sequence terminates.

This resolves the β\betaβ-Barendregt–Geuvers–Klop conjecture, including nonfunctional rules and open contexts.

论文

  1. 纯类型系统中的弱正规化与强正规化

    Weak and strong normalization in pure type systems

    摘要

    我们证明，每个弱 β-正规化的纯类型系统都是强 β-正规化的。

    这两个性质的量词均遍及所有有效上下文中的所有合法表达式，且归约作用于类型标注内部。

    不需要 functionality 假设。

    这解决了 β-Barendregt–Geuvers–Klop 猜想。

    英文原文

    We prove that every weakly β-normalizing pure type system is strongly β-normalizing.

    Both properties quantify over all legal expressions in all valid contexts, and reduction acts inside type annotations.

    No functionality hypothesis is required.

    This resolves the β-Barendregt–Geuvers–Klop conjecture.

# Weak normalization implies strong normalization in pure type systems

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Weak and strong normalization in pure type systems](../../preprints/Weak-and-strong-normalization-in-pure-type-systems-September-25-2026/paper.pdf)

## Scope

The formalization proves the $\beta$-Barendregt–Geuvers–Klop conjecture for pure type systems: if every legal expression in every valid context has some terminating $\beta$-reduction sequence, then every $\beta$-reduction sequence from every such expression terminates. Reduction is allowed inside type annotations, and the specification may have arbitrary sorts and nonfunctional axioms or rules.
