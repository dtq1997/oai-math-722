无密钥的纠缠与 PPT 平方猜想反例

Entanglement without secret key and the PPT-square conjecture

OpenAI · 2026-10-061 篇论文Lean 代码已公开

在 C10⊗C10\mathbb C^{10}\otimes\mathbb C^{10}C10⊗C10 上构造了一个纠缠态，对于所指定的几乎必然完成的局部量子仪器协议，其可蒸馏密钥为零。

这些协议允许联合的局部处理以及经过身份认证的双向公共通信，不使用其他共享私有资源，并设定窃听者持有输入态的纯化及公共记录。

在 M21(C)M_{21}(\mathbb C)M21​(C) 上构造的一个保迹 PPT 信道，其平方并非纠缠破坏信道，从而否定了 Christandl 的 PPT 平方猜想。

英文原文

Constructs an entangled state on C10⊗C10\mathbb C^{10}\otimes\mathbb C^{10}C10⊗C10 with zero distillable secret key for the specified local-instrument protocols that complete almost surely.

These allow joint local processing and authenticated two-way public communication, with no other shared private resource and an eavesdropper holding the input purification and public record.

A trace-preserving PPT channel on M21(C)M_{21}(\mathbb C)M21​(C) whose square is not entanglement breaking disproves Christandl’s PPT-square conjecture.

  1. 局部维数为十、可蒸馏秘密密钥为零的纠缠态

    Entanglement with zero distillable secret key in local dimension ten

    摘要

    我们在 C10⊗C10\mathbb C^{10}\otimes\mathbb C^{10}C10⊗C10 上构造了一个纠缠态，对于本文指定的局部量子仪器协议，其可蒸馏秘密密钥为零。

    这些协议允许联合处理全部副本以及无限制的双向公开通信，其中输入是唯一共享的私有资源，而窃听者持有一个纯化及全部公开记录。

    该构造还反驳了不加限制的两个映射的 PPT 复合猜想。

    另外，M21(C)M_{21}(\mathbb C)M21​(C) 上存在一个保迹 PPT 信道，其平方不是纠缠破坏信道。

    英文原文

    We construct an entangled state on C10⊗C10\mathbb C^{10}\otimes\mathbb C^{10}C10⊗C10 with zero distillable secret key for the local-instrument protocols specified here.

    They allow joint processing of all copies and unlimited two-way public communication, with the input as the only shared private resource and an eavesdropper holding a purification and the complete public record.

    The construction also disproves the unrestricted two-map PPT-composition conjecture.

    A separate trace-preserving PPT channel on M21(C)M_{21}(\mathbb C)M21​(C) has a square that is not entanglement breaking.

# Entanglement without distillable secret key

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Entanglement with zero distillable secret key in local dimension ten](../../preprints/Entanglement-with-zero-distillable-secret-key-in-local-dimension-ten-September-27-2026/paper.pdf)

## Scope

The paper's entanglement construction yields counterexamples to PPT-composition claims. The linked formalization covers these consequences: two explicitly specified PPT maps on $10\times10$ complex matrices have a composition that is not entanglement breaking, and the nonzero Choi matrix of that composition has no nonzero product vector in its range. A separate trace-preserving PPT channel on $21\times21$ matrices has a square that is not entanglement breaking.

The paper's zero-distillable-secret-key statement is outside these two selected Comparator statements.
