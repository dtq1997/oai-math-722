    Global Uniqueness for the Smooth Isotropic Elasticity Inverse Problem

    摘要

    我们证明，在 ℝ3 中每个有界连通光滑域上，只要在闭包上有 μ > 0 和 3λ+2μ>03\lambda+2\mu\gt 03λ+2μ>0，完整的静态位移到牵引力映射就唯一确定两个实光滑 Lamé 模量。

    这在这些正性假设下解决了光滑三维各向同性弹性 Calderón 唯一性问题。

    英文原文

    We prove that the full static displacement-to-traction map uniquely determines both real smooth Lamé moduli on every bounded connected smooth domain in ℝ3, provided μ > 0 and 3λ+2μ>03\lambda+2\mu\gt 03λ+2μ>0 on the closure.

    This resolves the smooth three-dimensional isotropic elastic Calderón uniqueness problem under these positivity assumptions.

# Global uniqueness in smooth isotropic elasticity

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Global Uniqueness for the Smooth Isotropic Elasticity Inverse Problem](../../preprints/Global-Uniqueness-for-the-Smooth-Isotropic-Elasticity-Inverse-Problem-September-24-2026/article.pdf)

## Scope

The formalization proves global uniqueness in the three-dimensional static isotropic elasticity inverse problem. On a bounded connected smooth domain, let two pairs of smooth real Lamé moduli satisfy $\mu>0$ and $3\lambda+2\mu>0$ on the closure. If their full displacement-to-traction maps agree, then both Lamé moduli agree throughout the domain. The selected statement is uniqueness; it does not supply a reconstruction algorithm.
