平均收益、随机及奇偶博弈的准多项式算法

Quasipolynomial algorithms for mean-payoff, stochastic and parity games

OpenAI · 2026-10-064 篇论文Lean 代码已公开

对于普通平均收益博弈及其两个独立的推广，给出了使用 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) 次位运算的确定性算法，其中 LLL 为完整的二进制输入长度。

这些算法计算普通博弈中的精确值和最优位置策略、轮流行动的随机博弈中以“下极限的期望”定义的值非负的集合，以及下极限平均收益非负且同时满足奇偶条件时的获胜集。

带符号奖励、有理的随机转移概率和奇偶优先级都不受限制，并以二进制编码。

英文原文

Gives deterministic algorithms using 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) bit operations, for complete binary input length LLL, for ordinary mean-payoff games and two separate extensions.

They compute exact values and optimal positional strategies in ordinary games, the nonnegative expectation-of-liminf value set in turn-based stochastic games, and the winning set for nonnegative liminf mean payoff conjoined with parity.

Signed rewards, rational chance probabilities, and parity priorities are unrestricted and binary-encoded.

  1. 轮流行动随机平均收益博弈的确定性准多项式时间算法

    Turn-Based Stochastic Mean-Payoff Games in Deterministic Quasipolynomial Time

    摘要

    对于奖励为有符号整数、随机转移概率为二进制编码有理数的有限轮流行动随机平均收益博弈，我们给出一个一致的确定性准多项式时间算法。

    对于逐路径下极限平均收益的期望，该算法精确计算具有非负值的顶点，包括值为零的顶点。

    该算法使用精确有理数算术和 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) 次位运算，其中 L 是完整的二进制输入长度。

    英文原文

    We give a uniform deterministic quasipolynomial-time algorithm for finite turn-based stochastic mean-payoff games with signed integer rewards and rational chance-transition probabilities encoded in binary.

    It computes exactly the vertices of nonnegative value, including value zero, for the expectation of the pathwise liminf mean payoff.

    The algorithm uses exact rational arithmetic and 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) bit operations, where L is the complete binary input length.

  2. 平均收益奇偶博弈的准多项式时间算法

    Mean-payoff parity games in quasipolynomial time

    摘要

    我们给出平均收益奇偶博弈的一个一致的确定性准多项式时间算法。

    对于任意有符号二进制编码奖励和不受限制的二进制编码优先级，该算法计算所有满足如下条件的顶点：某位玩家从该顶点出发可以同时保证非负的下极限平均收益和奇偶条件。

    运行时间为 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) 次位运算，其中 L 是完整输入长度。

    英文原文

    We give a uniform deterministic quasipolynomial-time algorithm for mean-payoff parity games.

    It computes all vertices from which a player can enforce both nonnegative liminf mean payoff and the parity condition, with arbitrary signed binary rewards and unrestricted binary priorities.

    The running time is 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) bit operations, where L is the complete input length.

  3. 平均收益博弈的确定性准多项式时间算法

    Deterministic quasipolynomial-time mean-payoff games

    摘要

    对于边权为二进制编码的任意有符号整数的有限平均收益博弈，我们给出一个计算完整零阈值获胜集的确定性算法。

    当显式输入的总长度为 L 时，它使用 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) 次位运算。

    通过一个归约，还可以在同样的准多项式界内计算每个顶点的精确有理值，以及双方玩家的全局最优位置策略。

    英文原文

    We give a deterministic algorithm that computes the complete zero-threshold winning set of a finite mean-payoff game with arbitrary signed integer edge weights encoded in binary.

    For total explicit input length L, it uses 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) bit operations.

    A reduction also computes the exact rational value at every vertex and globally optimal positional strategies for both players within the same quasipolynomial bound.

  4. 平均收益博弈的随机准多项式时间算法

    Randomized quasipolynomial-time mean-payoff games

    主结果已列入形式化清单
    摘要

    对于边权为二进制编码的任意有符号整数的有限平均收益博弈，我们给出一个计算完整零阈值获胜集的随机算法。

    当显式输入的总长度为 L 时，它在每条随机带上都使用 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) 次位运算，且正确概率至少为 7/8。

    一个多项式时间检查能够认证双方玩家的获胜区域和位置策略，或报告失败。

    因此，独立重复运行会给出一个始终正确的算法，其期望位运算次数满足同样的准多项式界。

    英文原文

    We give a randomized algorithm that computes the complete zero-threshold winning set of a finite mean-payoff game with arbitrary signed integer edge weights encoded in binary.

    For total explicit input length L, it uses 2O((log⁡(L+2))2)2^{O((\log(L+2))^2)}2O((log(L+2))2) bit operations on every random tape and is correct with probability at least 7/8.

    A polynomial-time check certifies the winning regions and positional strategies for both players or reports failure.

    Independent repetition therefore gives an always-correct algorithm with the same expected quasipolynomial bit bound.

# Quasipolynomial algorithms for mean-payoff, stochastic and parity games

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Deterministic quasipolynomial-time mean-payoff games](../../preprints/Deterministic-quasipolynomial-time-mean-payoff-games-September-25-2026/paper.pdf)
- [Randomized quasipolynomial-time mean-payoff games](../../preprints/Randomized-quasipolynomial-time-mean-payoff-games-September-25-2026/paper.pdf)

## Scope

The formalization checks that a specified two-step execution of Truffet's elimination procedure terminates with a feasible but nonoptimal output. It is a finite counterexample to that proposed optimization step.

The formalized result gives one randomized algorithm for the complete zero-threshold winning set of every finite mean-payoff game with signed binary weights. It succeeds with probability at least $7/8$ and runs in quasipolynomial bit time on every random tape. Self-loops, parallel edges, and history-dependent strategies are allowed, and winning means a nonnegative liminf average payoff.
