  1. 编辑距离的近线性时间近似方案

    An Almost-Linear Approximation Scheme for Edit Distance

    摘要

    我们给出单位代价编辑距离的一个一致的随机近似方案。

    对于每个固定有理数 ε∈(0,1)\varepsilon\in(0,1)ε∈(0,1)，它在字长为对数级的 RAM 上，以 N1+o(1)N^{1+o(1)}N1+o(1) 的最坏情形期望时间估计任意显式存储、总长度为 N 的字符串之间的距离，并以至少 2/3 的概率达到 1+ε1+\varepsilon1+ε 的近似因子。

    该算法支持多项式有界的整数字母表，并对相同字符串确定性地返回零。

    英文原文

    We give a uniform randomized approximation scheme for unit-cost edit distance.

    For every fixed rational ε∈(0,1)\varepsilon\in(0,1)ε∈(0,1), it estimates the distance between arbitrary explicitly stored strings of total length N within a factor 1+ε1+\varepsilon1+ε with probability at least 2/3, in worst-case expected time N1+o(1)N^{1+o(1)}N1+o(1) on a logarithmic-word RAM.

    The algorithm supports polynomially bounded integer alphabets and returns zero deterministically on equal strings.

# Almost-linear approximation of edit distance

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [An Almost-Linear Approximation Scheme for Edit Distance](../../preprints/An-Almost-Linear-Approximation-Scheme-for-Edit-Distance-September-24-2026/paper.pdf)

## Scope

The formalization gives a randomized $(1+\varepsilon)$-approximation for unit-cost edit distance between explicitly stored integer strings, for every fixed rational $0<\varepsilon<1$. Its estimate is at least the true distance and at most $(1+\varepsilon)$ times it with probability at least $2/3$; equal strings return zero on every execution.

For total length at most $N$ and integer symbols bounded by a fixed polynomial in $N$, expected work is at most $(N+2)^{1+\eta}$ for every fixed $\eta>0$ and all sufficiently large $N$. Space is polynomially bounded on every execution.
