整体球壳猜想

The Global Spherical Shell conjecture

OpenAI · 2026-10-061 篇论文未见公开 Lean 代码

每个满足 b2>0b_2>0b2​>0 的 VII 类连通极小紧复曲面都含有整体球壳，从而证明了正 b2b_2b2​ 情形下的整体球壳猜想。

这样的球壳是 C2∖{0}\mathbb C^2\setminus\{0\}C2∖{0} 中标准三维球面的一个邻域在该曲面中的全纯嵌入像，且其补集连通。

英文原文

Every connected minimal compact complex surface of class VII with b2>0b_2>0b2​>0 contains a global spherical shell, proving the positive-b2b_2b2​ Global Spherical Shell conjecture.

Such a shell is a holomorphically embedded neighborhood of the standard three-sphere in C2∖{0}\mathbb C^2\setminus\{0\}C2∖{0} whose complement is connected.

OpenAI · overview.tex

论文

  1. VII 类极小曲面上的整体球壳

    Global Spherical Shells on Minimal Surfaces of Class VII

    摘要

    我们证明了整体球壳猜想：每个第二 Betti 数为正的 VII 类连通极小紧复曲面都包含一个整体球壳。

    这是 C2∖{0}\mathbb C^2\setminus\{0\}C2∖{0} 中标准三维球面的一个全纯嵌入的邻域，其补集连通。

    英文原文

    We prove the Global Spherical Shell conjecture: every connected minimal compact complex surface of class VII with positive second Betti number contains a global spherical shell.

    This is a holomorphically embedded neighborhood of the standard three-sphere in C2∖{0}\mathbb C^2\setminus\{0\}C2∖{0} whose complement is connected.
