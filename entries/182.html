无多项式差值集合的幂次改善

Power savings for polynomial-difference-free sets

OpenAI · 2026-10-063 篇论文Lean 代码已公开

对每个固定的、次数为 k≥2k\ge2k≥2 且首项系数为正的 intersective 整系数多项式 hhh，证明了 {1,…,N}\{1,\ldots,N\}{1,…,N} 中任何以元素之差避开 h(1),h(2),…h(1),h(2),\ldotsh(1),h(2),… 中所有非零值的子集，其大小均为 Oh(N1−ck)O_h(N^{1-c_k})Oh​(N1−ck​)，其中 ck>0c_k>0ck​>0 只依赖于次数。

这里，intersective 指模每个模数都有根。

对于素数自变量，当 hhh 模每个模数都有一个可逆剩余类作为根时，也成立幂次改进，此时允许指数依赖于 hhh。

英文原文

For every fixed intersective integer polynomial hhh of degree k≥2k\ge2k≥2 with positive leading coefficient, proves that a subset of {1,…,N}\{1,\ldots,N\}{1,…,N} avoiding nonzero values h(1),h(2),…h(1),h(2),\ldotsh(1),h(2),… as differences has size Oh(N1−ck)O_h(N^{1-c_k})Oh​(N1−ck​), with ck>0c_k>0ck​>0 depending only on degree.

Here intersective means having a root modulo every modulus.

For prime arguments, a power saving also holds when hhh has a unit root modulo every modulus, with exponent allowed to depend on hhh.

  1. 模任意正整数有根的多项式差值界的幂次改进：指数仅依赖于次数

    A power saving for intersective polynomial differences with an exponent depending only on the degree

    摘要

    若一个整系数多项式对每个正整数取模都有根，则称其为 intersective。

    对于每个次数 k ≥ 2，我们证明，存在指数 ck>0c_k\gt 0ck​>0，使得每个差值避开 h(1),h(2),…h(1),h(2),\ldotsh(1),h(2),… 中所有非零值的集合 A⊆{1,…,N}A\subseteq\{1,\ldots,N\}A⊆{1,…,N} 都满足 ∣A∣=Oh(N1−ck)|A|=O_h(N^{1-c_k})∣A∣=Oh​(N1−ck​)，其中 h 是一个次数为 k、首项系数为正的 intersective 多项式。

    隐含常数可以依赖于 h，但幂次改进的指数仅依赖于它的次数。

    英文原文

    An integer polynomial is intersective if it has a root modulo every positive integer.

    For each degree k ≥ 2, we prove that there is an exponent ck>0c_k\gt 0ck​>0 such that every set A⊆{1,…,N}A\subseteq\{1,\ldots,N\}A⊆{1,…,N} whose differences avoid all nonzero values h(1),h(2),…h(1),h(2),\ldotsh(1),h(2),…, where h is an intersective polynomial of degree k with positive leading coefficient, satisfies ∣A∣=Oh(N1−ck)|A|=O_h(N^{1-c_k})∣A∣=Oh​(N1−ck​).

    The implied constant may depend on h, but the power-saving exponent depends only on its degree.

  2. 素数自变量处多项式差值界的幂次改进

    A Power Saving for Polynomial Differences at Prime Arguments

    摘要

    设 h 是一个固定的整系数多项式，其次数至少为二、首项系数为正，且对每个正整数取模都有一个可逆元根。

    我们证明，每个差值避开所有素数处的非零值 h(p)h(p)h(p) 的集合 A⊆{1,…,N}A\subseteq\{1,\ldots,N\}A⊆{1,…,N} 都满足 ∣A∣≤ChN1−ch|A|\le C_hN^{1-c_h}∣A∣≤Ch​N1−ch​，其中 ch>0c_h\gt 0ch​>0 和 Ch≥1C_h\ge1Ch​≥1 仅依赖于 h。

    因此，即使将多项式的自变量限制为素数，该局部可逆元根条件也给出一个固定的幂次改进。

    证明使用姊妹论文中关于 Dirichlet L-函数的无零点半平面定理，以获得所需的素数分布估计。

    英文原文

    Let h be a fixed integer polynomial of degree at least two with positive leading coefficient, having a unit root modulo every positive integer.

    We prove that any set A⊆{1,…,N}A\subseteq\{1,\ldots,N\}A⊆{1,…,N} whose differences avoid all nonzero values h(p)h(p)h(p) at primes satisfies ∣A∣≤ChN1−ch|A|\le C_hN^{1-c_h}∣A∣≤Ch​N1−ch​, where ch>0c_h\gt 0ch​>0 and Ch≥1C_h\ge1Ch​≥1 depend only on h.

    Thus the local unit-root condition gives a fixed power saving even when polynomial arguments are restricted to primes.

    The proof uses the companion zero-free half-plane theorem for Dirichlet L-functions to obtain the required prime-distribution estimates.

  3. 无非零平方差集合大小界的幂次改进

    A power saving for square-difference-free sets

    摘要

    我们证明，存在绝对常数 c > 0 和 C < ∞，使得每个不含非零平方数差值的集合 A⊆{1,…,N}A\subseteq\{1,\ldots,N\}A⊆{1,…,N} 都满足 ∣A∣≤CN1−c|A|\le C N^{1-c}∣A∣≤CN1−c。

    这回答了 Green 和 Sawhney 提出的固定幂次问题。

    英文原文

    We prove that there are absolute constants c > 0 and C < ∞ such that every set A⊆{1,…,N}A\subseteq\{1,\ldots,N\}A⊆{1,…,N} with no nonzero square difference satisfies ∣A∣≤CN1−c|A|\le C N^{1-c}∣A∣≤CN1−c.

    This answers the fixed-power question posed by Green and Sawhney.

# Power savings for intersective polynomial differences and prime arguments

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [A power saving for square-difference-free sets](../../preprints/A-power-saving-for-square-difference-free-sets-September-24-2026/paper.pdf)

## Scope

The formalization proves a fixed power saving for sets with no nonzero square difference. There are absolute constants $c>0$ and $C$ such that every $A\subseteq\{1,\ldots,N\}$ satisfying $a-b\ne m^2$ for all $a,b\in A$ and integers $m\ge1$ has $|A|\le C N^{1-c}$. The bound is uniform for every integer $N\ge1$.
