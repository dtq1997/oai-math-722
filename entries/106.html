三可染色图的染色困难性

Hardness of coloring three-colorable graphs

OpenAI · 2026-10-061 篇论文Lean 代码已公开

对可三着色图使用任意固定的 c≥3c\ge3c≥3 种颜色着色是 NP-难的。

更强地，对每个固定的 0<δ<1/30<\delta<1/30<δ<1/3，存在从 333SAT 出发的确定性多项式时间归约，生成简单无权图，使其在可满足情形下可三着色，否则不含大小为 δn\delta nδn 的独立集，其中 nnn 为顶点数。

英文原文

It is NP-hard to color a three-colorable graph using any fixed number c≥3c\ge3c≥3 of colors.

More strongly, for every fixed 0<δ<1/30<\delta<1/30<δ<1/3, a deterministic polynomial-time reduction from 333SAT produces simple unweighted graphs that are three-colorable in the satisfiable case and have no independent set of size δn\delta nδn otherwise, where nnn is the number of vertices.

论文

  1. 在可三着色图中寻找大独立集的困难性

    Hardness of finding large independent sets in three-colorable graphs

    主结果已列入形式化清单
    摘要

    我们证明，对于每个固定的 0<δ<1/30\lt \delta\lt 1/30<δ<1/3，区分可三着色图与其中每个独立集的大小都严格小于顶点数的 δ 倍的图，是 NP-hard 的。

    因此，对于每个固定整数 c ≥ 3，寻找可三着色图的一个正常 c 着色是 NP-hard 的。

    英文原文

    We prove that, for every fixed 0<δ<1/30\lt \delta\lt 1/30<δ<1/3, it is NP-hard to distinguish three-colorable graphs from graphs in which every independent set has fewer than δ times the number of vertices.

    Consequently, for every fixed integer c ≥ 3, finding a proper c-coloring of a three-colorable graph is NP-hard.

# Hardness of coloring three-colorable graphs

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Hardness of finding large independent sets in three-colorable graphs](../../preprints/Hardness-of-finding-large-independent-sets-in-three-colorable-graphs-September-24-2026/Hardness-of-finding-large-independent-sets-in-three-colorable-graphs-September-24-2026.pdf)

## Scope

The formalized result shows hardness of finding large independent sets even under a three-colorability promise. For every fixed $0<\delta<1/3$, a deterministic polynomial-time reduction maps binary 3SAT formulas to nonempty finite simple graphs. Satisfiable formulas produce three-colorable graphs; unsatisfiable formulas produce graphs whose largest independent set has fewer than $\delta$ times the number of vertices. The complete adjacency-matrix output is included in the runtime bound.
