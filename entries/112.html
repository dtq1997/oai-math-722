深度三电路超越平方根指数的下界

Beyond the square-root exponent for depth-three circuits

OpenAI · 2026-10-061 篇论文Lean 代码已公开

构造了一个可在确定性多项式时间内判定的语言，其 nnn 位成员判定函数在无界扇入的 OR–AND–OR 电路中总共需要 2ω(n)2^{\omega(\sqrt n)}2ω(n​) 个门，而且这对每个充分大的输入长度都成立。

这突破了显式深度三布尔电路下界的平方根指数门槛。

英文原文

Constructs a single language in deterministic polynomial time whose nnn-bit membership function requires 2ω(n)2^{\omega(\sqrt n)}2ω(n​) total gates in unbounded-fan-in OR–AND–OR circuits, at every sufficiently large input length.

This crosses the square-root-exponent threshold for explicit depth-three Boolean circuit lower bounds.

    英文原文

    We construct a language in deterministic polynomial time whose n-bit membership function requires 2ω(n)2^{\omega(\sqrt n)}2ω(n​) gates in an unbounded-fan-in OR–AND–OR circuit.

    The bound holds at every sufficiently large input length and counts all gates, including the bottom layer.

# Beyond the square-root exponent for depth-three circuits

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Beyond the Square-Root Exponent for Depth-Three Boolean Circuits](../../preprints/Beyond-the-Square-Root-Exponent-for-Depth-Three-Boolean-Circuits-September-23-2026/main.pdf)

## Scope

The formalized result gives one polynomial-time Boolean language whose exact depth-three OR–AND–OR circuit size eventually exceeds $2^{A\sqrt n}$ for every fixed $A>0$. The language and its polynomial-time algorithm are fixed before $A$ is chosen, while circuits may vary with the input length. Gates have unrestricted finite fan-in and sharing, with free input negations and constants. The result does not assert a fixed exponent $n^{1/2+\varepsilon}$ or a lower bound for unrestricted depth.
