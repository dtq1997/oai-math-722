低于 n ln n 的整数乘法

Integer multiplication below nlog⁡nn\log nnlogn

OpenAI · 2026-10-061 篇论文未见公开 Lean 代码

在一台固定的、字母表有限且仅有有限条一维纸带的 Turing 机上，对每个输入长度，都能在确定性最坏情形时间 O(n(log⁡n)1−κ)O(n(\log n)^{1-\kappa})O(n(logn)1−κ) 内精确计算两个 nnn 位整数的乘积，其中 κ=2−182\kappa=2^{-182}κ=2−182。

这否定了普通多纸带位模型中的 Schönhage–Strassen nlog⁡nn\log nnlogn 最优性猜想。

英文原文

Multiplies two nnn-bit integers exactly at every input length in deterministic worst-case time O(n(log⁡n)1−κ)O(n(\log n)^{1-\kappa})O(n(logn)1−κ), with κ=2−182\kappa=2^{-182}κ=2−182, on one fixed finite-alphabet Turing machine with finitely many one-dimensional tapes.

This disproves the Schönhage–Strassen nlog⁡nn\log nnlogn optimality conjecture in the ordinary multitape bit model.

  1. 低于 n log n 时间的整数乘法

    Integer multiplication below n log n

    摘要

    我们给出一个确定性算法，在一台固定的、具有固定有限条一维带的有限字母表图灵机上，以 O(n(lg⁡n)1−κ)O(n(\lg n)^{1-\kappa})O(n(lgn)1−κ) 的最坏情形时间将两个 n 位整数相乘，其中 κ=2−182\kappa=2^{-182}κ=2−182。

    该算法对每个输入长度都是精确的，并否定了 Schönhage 和 Strassen 在此模型下的 nlog⁡nn\log nnlogn 最优性猜想。

    英文原文

    We give a deterministic algorithm that multiplies two n-bit integers in O(n(lg⁡n)1−κ)O(n(\lg n)^{1-\kappa})O(n(lgn)1−κ) worst-case time, with κ=2−182\kappa=2^{-182}κ=2−182, on one fixed finite-alphabet Turing machine with a fixed finite number of one-dimensional tapes.

    The algorithm is exact for every input length and disproves the nlog⁡nn\log nnlogn optimality conjecture of Schönhage and Strassen in this model.
