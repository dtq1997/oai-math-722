禁用子图条件下的染色与独立集

Coloring and independence in graphs with forbidden subgraphs

OpenAI · 2026-10-062 篇论文Lean 代码已公开

以对应染色的形式证明了 Alon–Krivelevich–Sudakov 染色猜想：不含任意一个固定子图 FFF 的图，在其最大度数 Δ\DeltaΔ 充分大时，只需 OF(Δ/log⁡Δ)O_F(\Delta/\log\Delta)OF​(Δ/logΔ) 种颜色。

还证明了 Ajtai–Erdős–Komlós–Szemerédi 独立集猜想：对固定的 r≥4r\ge4r≥4，每个有 nnn 个顶点、不含 KrK_rKr​ 且平均度数为 d≥2d\ge2d≥2 的图，都有一个大小为 Ωr(nlog⁡d/d)\Omega_r(n\log d/d)Ωr​(nlogd/d) 的独立集。

英文原文

Proves the Alon–Krivelevich–Sudakov coloring conjecture in correspondence-coloring form: graphs avoiding any fixed subgraph FFF need OF(Δ/log⁡Δ)O_F(\Delta/\log\Delta)OF​(Δ/logΔ) colors when their maximum degree Δ\DeltaΔ is sufficiently large.

Also proves the Ajtai–Erdős–Komlós–Szemerédi independence conjecture: for fixed r≥4r\ge4r≥4, every nnn-vertex KrK_rKr​-free graph of average degree d≥2d\ge2d≥2 has an independent set of size Ωr(nlog⁡d/d)\Omega_r(n\log d/d)Ωr​(nlogd/d).

  1. 不含指定团的图的对应染色

    Correspondence coloring graphs with a forbidden clique

    摘要

    对于每个固定整数 r ≥ 4，我们证明，每个最大度 Δ 充分大的不含 Kr 的图，其对应色数为 Or(Δ/log⁡Δ)O_r(\Delta/\log\Delta)Or​(Δ/logΔ)。

    这以更强的对应染色形式解决了 Alon–Krivelevich–Sudakov 染色猜想。

    当排除任意一个固定图 F 作为普通子图时，同样的界也成立，其中常数依赖于 F。

    普通染色和列表染色满足相同的界。

    英文原文

    For every fixed integer r ≥ 4, we prove that every Kr-free graph of sufficiently large maximum degree Δ has correspondence chromatic number Or(Δ/log⁡Δ)O_r(\Delta/\log\Delta)Or​(Δ/logΔ).

    This resolves the Alon–Krivelevich–Sudakov coloring conjecture in the stronger correspondence-coloring form.

    The same bound, with a constant depending on F, holds when any fixed graph F is excluded as an ordinary subgraph.

    Ordinary and list coloring satisfy the same bounds.

    A logarithmic independence bound for clique-free graphs

    摘要

    对于每个固定整数 r ≥ 4，每个具有 n 个顶点、平均度为 d ≥ 2 且不含 Kr 的图，都有一个大小至少为 crnlog⁡d/dc_r n\log d/dcr​nlogd/d 的独立集，其中 cr>0c_r\gt 0cr​>0 仅依赖于 r。

    英文原文

    For every fixed integer r ≥ 4, every Kr-free graph on n vertices with average degree d ≥ 2 has an independent set of size at least crnlog⁡d/dc_r n\log d/dcr​nlogd/d, where cr>0c_r\gt 0cr​>0 depends only on r.

    This proves the fixed-clique-size independence conjecture of Ajtai, Erdős, Komlós and Szemerédi.

# Correspondence coloring with a fixed forbidden subgraph

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [A logarithmic independence bound for clique-free graphs](../../preprints/A-Logarithmic-Independence-Bound-for-Clique-Free-Graphs-September-25-2026/paper.pdf)

## Scope

The formalized result gives a logarithmic improvement in the independence number of clique-free graphs. For every fixed integer $r\ge4$, there is $c_r>0$ such that every finite $K_r$-free simple graph on $n$ vertices with average degree $d\ge2$ has an independent set of size at least $c_r n\log d/d$. The constant depends only on $r$.
